# Azure/EntraID AI-Powered Threat Detection
Project Overview
This project demonstrates the development of an AI-powered security tool using Azure OpenAI to analyze Microsoft Entra ID (Azure AD) sign-in logs and automatically detect suspicious authentication behavior such as impossible travel and brute-force attempts.

---

## Key Features
- Built an end-to-end workflow in n8n that simulates data input and applies logic.  
- Implemented conditional branching for different automated outputs (e.g., sunny vs. rainy responses).  
- Gained hands-on experience in workflow automation, decision-making, and building lightweight AI agents.
